# GNITS Smart Campus — UI Upgrade

This package keeps the existing application flow and backend contracts intact.

## Visual changes
- GNITS-inspired deep navy / blue enterprise palette with neon status accents.
- Immersive photographic hero treatment on splash, login and dashboard.
- Dashboard redesigned as a command-center home experience.
- Live Occupancy room cards now use contextual classroom / seminar-hall photography with a dark glass overlay so room text remains readable.
- Occupancy cards preserve the real status, room type, capacity, subject/section and timetable times returned by the backend.
- Live-sync indicators, premium glass panels, stronger hierarchy and responsive layouts.
- Existing navigation, role-based access, timetable upload, booking, rooms and reports remain present.

## Important
The photographic backgrounds are remote Unsplash images, so the enhanced visual treatment needs network access. No new backend API or database schema is required for this UI upgrade.

Backend package is supplied separately and is unchanged from the uploaded version.
