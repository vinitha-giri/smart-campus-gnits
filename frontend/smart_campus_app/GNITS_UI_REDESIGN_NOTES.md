# GNITS Smart Campus – Website-Matched UI Refresh

This build refreshes the presentation layer to align the Smart Campus app with GNITS institutional identity while preserving existing functionality.

## UI changes only
- GNITS-inspired navy, orange, academic blue and clean white visual system
- GNITS crest loaded from the official GNITS website with a safe icon fallback
- GNITS tagline and institutional naming on splash/login/dashboard
- Responsive branded dashboard hero
- Refined sidebar, cards, controls, KPIs and booking palette
- Improved mobile layouts and spacing

## Existing behavior preserved
- Role-based login credentials and access
- Backend/API endpoints
- Live occupancy
- Rooms and filtering
- Timetable upload/template workflow
- Room booking and cancellation
- Reports and analytics
- Navigation and refresh behavior

The official website content itself is not embedded in this stage; this version focuses on making the existing Smart Campus application visually feel native to GNITS.
